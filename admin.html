Project Admin

Edit, add, or remove public projects and save them to Supabase, or export a new index.html.

The public site uses the Supabase project list when available. If Supabase is unavailable, it uses the last successful local cache; if there is no cache, it uses the embedded defaults. Publishing an exported index.html makes the latest values part of the static file itself.

Projects

Projects are shown on the public site three per row. Drag and drop the project tabs to change their order.

Saving to Supabase changes the live site. Exporting creates a static copy you can upload over index.html.
